# The Architect · Soluciones tecnológicas

Sitio de prueba de los servicios de Edwin Calderón y Daniela Rico: páginas web, Núcleo (punto de venta e inventario) y acompañamiento técnico en proyectos de grado.

- Estático: HTML, CSS y JavaScript sin dependencias. Se publica con GitHub Pages desde `main`.
- `assets/js/chat.js` es el motor del asistente (sin IA ni servidor) y `assets/js/chat-kb.js` su base de conocimiento.
- El formulario de contacto no envía nada a un servidor: arma el mensaje y abre WhatsApp.
- Videos y fotos generados con Google Flow (Veo 3.1 Lite) y Microsoft 365 Copilot (GPT-6.1 Sol), optimizados con ffmpeg.
